# Nova RFCs — Language Evolution & Technical Specifications

> **Open Design | Formal Semantics | Community RFC Process**

This repository contains Request for Comments (RFC) proposals for changes to the **Nova Systems Programming Language**, following the precedent established by `rust-lang/rfcs`.

---

## The RFC Life Cycle

1. **Idea / Discussion**: Open an issue or discussion thread.
2. **Drafting**: Fork this repository and draft `text/0000-my-feature.md` using `0000-template.md`.
3. **Pull Request**: Open a PR into `novasystems-dev/rfcs`.
4. **Final Comment Period (FCP)**: 14 days of formal review by the language steering team.
5. **Acceptance & Implementation**: Merged into `active/` and assigned a tracking issue in `novasystems-dev/nova`.
